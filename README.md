# Dhatri AI — Women's Health & Wellness Companion 🌸

Dhatri AI is an AI-powered women's health and wellness companion designed to provide accessible health education and self-care guidance.

## Features

- 🤖 **AI Health Assistant:** Women's health education and symptom guidance powered by Google Gemini.
- 🌐 **Multilingual Support:** English, Hindi, and Hinglish.
- 🎙️ **Voice Input:** Ask questions using speech instead of typing.
- 🥗 **Indian Diet Guidance:** Nutrition tips and iron-rich food suggestions.
- 🧘 **Wellness & Yoga:** Gentle yoga and period-cramp self-care guidance.
- 🌸 **Menstrual Health:** Educational information about menstrual cycles and related symptoms.
- 💬 **Chat Interface:** Interactive conversations with the AI assistant.

## Tech Stack

- Frontend: React, Vite, JavaScript
- Backend: Node.js, Express
- AI: Google Gemini API

## Getting Started

1. Clone this repository.
2. Install the project dependencies.
3. Configure your environment variables.
4. Start the frontend and backend using the project's development scripts.

Refer to `.env.example` and the project configuration files for setup instructions.

## Environment Variables

Configure your Gemini API key in the local server environment file:

`server/.env`

Never commit your real API key or other secrets to GitHub.
